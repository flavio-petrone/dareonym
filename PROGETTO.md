# Decisioni di prodotto — Dareonym 2

Flavio ha scelto una ricostruzione con database inizialmente vuoto e ha affidato la scelta del flusso alla revisione tecnica.

È stato implementato un percorso con approvazione delle prove da parte del creator: sfida → gruppo → fotografia e racconto → revisione → punti → classifica. Questo rende utile il ruolo del creator e dà ai punteggi una base verificabile.

Sono stati mantenuti i concetti del progetto originale, mentre codice, interfaccia e asset sono nuovi. Non sono state copiate le pagine o il template commerciale SB Admin Pro.

Priorità della prima versione: un percorso completo e testato, permessi per gruppo, fotografie persistenti e private, nessun doppio accredito, installazione web protetta e caricamento compatibile con un hosting PHP/MySQL. Le versioni PHP e il funzionamento dei divieti sui file privati devono ancora essere verificati sullo specifico account di hosting.

Non sono stati modificati o cancellati file e database del sito online. L’errore della versione precedente nello screenshot resta un messaggio generico; la ricostruzione non è una diagnosi retroattiva di quella configurazione.

La consegna è una prima versione 2.0 funzionante, non l’esaurimento di tutte le possibili evoluzioni. Funzioni future: recupero password via email, notifiche, esportazioni e gestione della conservazione dei dati, paginazione per comunità grandi, stagioni e badge. Il README distingue le funzioni presenti da queste possibili estensioni.
